## 📖 Overview

The **IPTV Streaming Platform** is a complete media solution combining a user-facing streaming experience with a full-featured **admin dashboard**. It includes live TV channels, an on-demand video library, subscription plans, user authentication, and an admin panel to manage content end-to-end.

---

## ✨ Key Features

- 📺 **Live TV Channels** — browse and watch live channels
- 🎬 **VOD Library** — on-demand video content
- 📅 **Subscription Plans** — pricing & plan selection page
- 👤 **Authentication** — sign up & sign in flows
- 🛠️ **Admin Dashboard** — content & user management panel
- 📱 **Responsive UI** — clean, modern, mobile-friendly design

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/Ali-Hassan-542/IPTV-Complete-with-Admin-Dashboard.git
   ```

2. **Open the app**
   - Double-click `index.html`, or
   - Serve the folder with **Live Server** (VS Code) for the best experience.

3. **Explore** the channel list, plans and the **Admin Dashboard** located inside the `Admin_dashboard/` folder.
