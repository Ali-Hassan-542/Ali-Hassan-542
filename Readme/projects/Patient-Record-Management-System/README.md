## 📖 Overview

The **Patient Record Management System (PRMS)** replaces outdated, paper-based record keeping with a centralized, reliable and secure digital platform. It enables **doctors, nurses and administrators** to access patient data, schedule appointments, generate reports and manage billing — through a clean, role-aware web interface.

---

## ✨ Key Features

- 👤 **Patient Records** — create, view, update and search patient medical history
- 📅 **Appointment Scheduling** — book and manage doctor appointments
- 💳 **Billing Management** — generate and track invoices & payments
- 🛡️ **Role-Based Access** — separate permissions for doctors, nurses & admins
- 📊 **Reports** — quick insights and reporting dashboards
- 📱 **Responsive UI** — mobile-friendly, modern Bootstrap-based design

## 🚀 Getting Started

### Prerequisites
- **XAMPP** or **WAMP** (Apache + PHP + MySQL)
- Modern web browser

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/Ali-Hassan-542/Patient-Record-Management-System.git
   ```

2. **Move the project** into your web server root:
   ```text
   C:\xampp\htdocs\prms
   ```

3. **Start the server** — launch Apache & MySQL from the XAMPP control panel.

4. **Set up the database** — create a database (e.g. `prms`) and configure the connection credentials in the config file inside the `admin/` directory.

5. **Run the app** — open your browser and visit:
   ```text
   http://localhost/prms
   ```
